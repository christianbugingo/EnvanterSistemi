# Currency catalogue provenance

`InventorySystemi/src/currencies/catalogue.tsv` is generated by `scripts/GenerateCurrencies.java` from java.util.Currency names/symbols, checked against the bundled `iso-current.xml` downloaded from the ISO 4217 maintenance agency. Defined minor units from the current register take precedence over older JDK metadata. One current code (UYW) is not known by this JDK; its published ISO name, code and 4 minor units are retained. There is no hand-maintained country list.

All 178 current ISO entries are retained in the table/resource. The 165 monetary/fund codes with numeric minor units are selectable. Special entries without defined precision are stored with minor units -1 and cannot price shop sales. Symbols are Java's English symbols and may equal the code; amount formatting deliberately uses an unambiguous currency-code suffix. The application never fetches updates online.

Sources: [Java 21 Currency API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Currency.html), [ISO currency codes](https://www.iso.org/iso-4217-currency-codes.html), [SIX current currency/funds register](https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml).

Refresh at development time with JDK 21:

```
java InventorySystemi/scripts/GenerateCurrencies.java InventorySystemi/src/currencies/iso-current.xml InventorySystemi/src/currencies/catalogue.tsv
```
